# 麦枢控制台

模式：Operate。现有控制台应用小麦知行已建立的 VI；路由、资源和执行语义延续原产品。

用户要求“麦枢的logo重新设计一个”“UI上，参考VI，看会话‘提炼小麦知行设计系统与VI’”。品牌关系已确认“独立产品符号，沿用小麦的深蓝与麦金”。源会话为 01a1e98d-78c9-7872-b4ac-e26ed2253b15，其交付包为“小麦知行_设计系统与VI_v1”。

## Direction contract

- THESIS：让用户读清真实任务和资源、找到操作入口；品牌由导航、字体和标志承载。
- OWN-WORLD：深蓝导航、纸白工作面、克制麦金选中；Noto Serif SC 统一文字；产品 M＋金节点独立于母品牌四麦粒。
- STORY：进入工作概览，查看最近会话，再进入智能体、执行环境和平台设置完成操作。
- FIRST VIEWPORT：保留左栏和顶栏；标题与说明、真实统计行、最近会话依次排列，接入说明在后。手机为抽屉导航、2×2统计和容器内横滚表格。
- FORM：沿用既有 Operate 结构，应用用户指定 VI；seed: none (existing system)。主 UI 16px、辅助14px、说明18px，主要控件44px。
- INTERACTION：沿用既有悬停、键盘焦点、禁用和加载反馈，不增加入场编舞。全屏启动使用新符号，减少动态效果生效。
- FINISH：独立审阅覆盖桌面1440/1280、手机390、浅深色、加载/禁用/错误/空状态；文件无匹配搜索修复已复验 resolved / ship。线上部署另做真实浏览器与资源摘要验收。

实际可复用令牌、组件和字体规则见上级 DESIGN.md；本说明不替代母品牌 VI。运行时原版 CONSOLE_BRANDING_DIR 继续可用；独立静态发布属于部署选项。
